# 🎬 Netflix Movies REST API

A Netflix-style backend application built using **Java 17** and **Spring Boot** that provides RESTful APIs to manage movies.  
This project demonstrates core backend concepts such as REST APIs, input validation, and in-memory data storage.

---

## 🚀 Features

- Add new movies  
- View all movies  
- View movie by ID  
- Delete a movie  
- Input validation using Jakarta Validation  
- In-memory data storage (no database)  
- Deployable on Render / Railway  

---

## 🛠 Tech Stack

- Java 17  
- Spring Boot 3.x  
- Maven  
- REST API  
- In-Memory Storage (ArrayList)
